# API reference

Interactive docs: **Swagger UI** at `/api/docs/` and the OpenAPI schema at `/api/schema/` (generated by drf-spectacular and validated in the test suite).

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/v1/route/` | Plan a trip (query parameters) |
| `POST` | `/api/v1/route/` | Plan a trip (JSON body, same fields) |
| `GET` | `/api/v1/route/map/` | The same trip as an HTML Leaflet map (same parameters) |
| `GET` | `/api/health/` | Status, Django version, data in memory, whether a key is set |
| `GET` | `/api/schema/`, `/api/docs/` | OpenAPI schema, Swagger UI |
| — | `/admin/` | Django admin (fuel stations) |

No authentication is required. The route and map endpoints are rate-limited (see [Rate limits](#rate-limits)).

## Parameters (`/api/v1/route/` and `/api/v1/route/map/`)

| Name | Type | Default | Allowed | Notes |
|---|---|---|---|---|
| `start` | string | **required** | ≤ 200 chars | `"City, ST"`, `"City, State"`, `"City ST"`, `"lat,lon"`, or a US street address |
| `finish` | string | **required** | ≤ 200 chars | same formats |
| `start_fuel` | string | `empty` | `empty`, `full`, or gallons > 0 and ≤ tank | see [ALGORITHM.md §3](ALGORITHM.md#3-start-fuel-modes) |
| `max_range_miles` | number | `500` | 50–1500 | tank = range ÷ mpg |
| `mpg` | number | `10` | 1–100 | |
| `corridor_miles` | number | `10` | 1–50 | maximum distance from the route to a station |
| `origin_radius_miles` | number | `25` | 1–100 | `empty` start: the first stop must be within this distance |
| `stop_penalty` | number | `15` | 0–200 | USD per stop added when *choosing* stops; `0` = pure cost optimum. Not added to `total_fuel_cost` |
| `profile` | string | `driving-car` | `driving-car`, `driving-hgv` | `driving-hgv` = heavy goods vehicle (truck) routing |
| `include_geometry` | boolean | `true` | `true`/`false` | `false` omits the GeoJSON (NYC → LA: 171 KB → 4 KB) |

How locations are resolved:
- `"lat,lon"` is checked offline against US bounds.
- `"City, ST"` is looked up in the offline Census gazetteer (0 calls).
- Canadian provinces and "Canada"/"Mexico" are rejected by name.
- Anything else, or a city the gazetteer doesn't know, is geocoded by ORS (US only) and cached for 30 days.

## Response (`200`)

```jsonc
{
  "start":  {"query": "Chicago, IL", "name": "Chicago, IL", "lat": 41.83705, "lon": -87.68494, "resolved_by": "offline"},
  "finish": {"query": "Houston, TX", "name": "Houston, TX", "lat": 29.78574, "lon": -95.38881, "resolved_by": "offline"},
  "summary": { … },        // see below
  "fuel_stops": [ … ],     // see below
  "route": {"type": "FeatureCollection", "features": [ … ]},   // null if include_geometry=false
  "map_url": "http://localhost:8000/api/v1/route/map/?start=…",
  "assumptions": ["Fuel prices are the retail prices in the provided OPIS CSV …", "…"],
  "meta": { … }
}
```

### `start` / `finish`

| Field | Meaning |
|---|---|
| `query` | Your input, as sent |
| `name` | The resolved place, e.g. `"St. Louis, MO"`, the ORS label, or `"lat,lon"` |
| `lat`, `lon` | Coordinates used for routing (5 decimals) |
| `resolved_by` | `offline` (gazetteer), `coordinates`, or `ors` |

### `summary`

| Field | Meaning |
|---|---|
| `total_distance_miles`, `estimated_duration_hours` | From the routed path |
| `fuel_consumed_gallons` | distance ÷ mpg |
| `gallons_purchased` | Bought at the stops |
| `initial_fuel_gallons` | In the tank at the start. In `empty` mode: the fuel burned to reach stop 1 |
| `initial_fuel_cost` | `empty`: that fuel charged at stop 1's price. Otherwise 0 |
| `total_fuel_cost` | **Money spent on fuel for this trip** = stop costs + `initial_fuel_cost` |
| `average_price_paid` | `total_fuel_cost` ÷ paid gallons |
| `average_corridor_price` | Mean price of all stations in the corridor |
| `baseline_cost_at_avg_corridor_price`, `estimated_savings` | The paid gallons at the corridor average, and how much less this plan costs |
| `number_of_stops`, `largest_leg_miles` | Largest distance between fuel sources (start, stops, finish); always ≤ range |
| `fuel_at_finish_gallons` | Usually 0; positive when the starting tank covers the trip |
| `stop_penalty` | The penalty used |
| `pure_cost_optimum` | `{total_fuel_cost, number_of_stops}` for the same trip with `stop_penalty=0` |
| `extra_cost_vs_pure_optimum` | Fuel money traded for fewer stops (0 when the penalty is 0) |
| `vehicle` | `{max_range_miles, mpg, tank_gallons}` |
| `start_fuel` | `empty`, `full`, or the number of gallons |

### `fuel_stops[]`

`order`, `station_id` (OPIS Truckstop ID), `name`, `address`, `city`, `state`, `lat`, `lon` (city-level), `price_per_gallon`, `mile_marker` (distance along the route), `off_route_miles`, `fuel_on_arrival_gallons`, `gallons_purchased`, `cost`, `fuel_on_departure_gallons`.

### `route`

A GeoJSON `FeatureCollection` with these features:
- one `LineString` (`properties.kind = "route"`), with vertices at least 0.25 mi apart along the path, in `[lon, lat]` order;
- `Point` features of kind `start`, `fuel_stop` (with `order`, `name`, `price_per_gallon`, `gallons_purchased`, `cost`, `mile_marker`) and `finish`.

### `meta`

| Field | Meaning |
|---|---|
| `external_api_calls` | Routing/geocoding API **operations** made for this response (0 on a cache hit) |
| `external_api_attempts` | HTTP attempts including retries. Larger than calls only if ORS timed out or failed |
| `cache_hit` | `true` if the response or the route came from the cache |
| `timings_ms` | `data_load`, `geocode`, `routing`, `geometry`, `corridor`, `optimize`, `pure_optimum`, `total`, `response`, `request_total`; on a response-cache hit, `response_cache` and `request_total` |
| `stations_considered` | Stations in the corridor |
| `corridor_miles`, `profile` | Echo of the parameters |
| `data_version` | Hash of the station dataset |
| `api_version` | `v1` |

## Errors

Every error uses one envelope:

```json
{"error": {"code": "location_outside_usa", "message": "'Toronto, ON' is not in the United States.", "details": {"query": "Toronto, ON"}}}
```

| HTTP | `code` | When |
|---|---|---|
| 400 | `invalid_input` | Missing or invalid parameter; `details` maps field → messages (e.g. `start_fuel` larger than the tank) |
| 400 | `parse_error` | Malformed JSON body |
| 405 | `method_not_allowed` | e.g. `PUT` |
| 422 | `location_not_found` | Nothing in the US matched the text |
| 422 | `location_outside_usa` | Coordinates or a named region outside the 50 states + DC |
| 422 | `same_location` | Start and finish resolve to within 0.5 mi of each other |
| 422 | `route_unreachable` | No drivable route (e.g. Hawaii → mainland), or a fuel gap larger than the range. `details` has `gap_start_mile`, `gap_end_mile`, `gap_start_near`, `gap_end_near` |
| 429 | `rate_limited` | Our throttle (`Retry-After` header) or the ORS quota |
| 502 | `routing_provider_error` | ORS returned an unexpected error |
| 503 | `routing_provider_unavailable` | ORS unreachable after retries, key rejected, or `ORS_API_KEY` missing |
| 503 | `station_data_unavailable` | No stations loaded (`manage.py load_stations`) |
| 504 | `routing_provider_timeout` | ORS didn't answer within the read timeout (30 s for directions) on both attempts |

The map page renders the same errors as an HTML page with the same status code.

## Caching and call budget

| Situation | Routing API calls |
|---|---|
| New trip, `"City, ST"` / `"lat,lon"` inputs | 1 |
| Identical request again (response cache, 24 h) | 0 |
| Same endpoints and profile, other vehicle parameters (route cache, 24 h) | 0 |
| `map_url` after the JSON request | 0 |
| Street address at one or both ends | +1 per address (geocode cache, 30 days) |

`python manage.py clear_cache` makes the next requests cold.

## Rate limits

`/api/v1/route/` and `/api/v1/route/map/` allow **30 requests per minute per client IP** (`ROUTE_THROTTLE_RATE`). This protects the free ORS quota of 2,000 directions requests per day and 40 per minute. Health and docs aren't throttled. Throttled responses are 429 `rate_limited` with a `Retry-After` header.

## curl examples

```bash
# City to city (GET), lean response
curl "localhost:8000/api/v1/route/?start=New%20York,%20NY&finish=Los%20Angeles,%20CA&include_geometry=false"

# JSON body, full tank, truck routing, pure cost optimum
curl -X POST localhost:8000/api/v1/route/ -H "Content-Type: application/json" \
  -d '{"start":"Chicago, IL","finish":"Houston, TX","start_fuel":"full","profile":"driving-hgv","stop_penalty":0}'

# Coordinates and a street address
curl "localhost:8000/api/v1/route/?start=40.7128,-74.0060&finish=34.0522,-118.2437"
curl "localhost:8000/api/v1/route/?start=1600%20Pennsylvania%20Ave%20NW,%20Washington,%20DC&finish=Chicago,%20IL"

# An error
curl "localhost:8000/api/v1/route/?start=Toronto,%20ON&finish=Chicago,%20IL"     # 422 location_outside_usa
```
